The objective :
Create a database
Create a table
Add a new column
Modify an existing column
Rename a table
Remove all records using TRUNCATE
Display available tables
learning utcomes
✅ Create a database using CREATE DATABASE
✅ Select a database using USE
✅ Create tables using CREATE TABLE
✅ Add columns using ALTER TABLE ... ADD COLUMN
✅ Modify columns using MODIFY COLUMN
✅ Rename tables using RENAME TABLE
✅ Check tables using SHOW TABLES
✅ Remove all table records using TRUNCATE TABLE
✅ Understand that TRUNCATE removes data but preserves the table structure
